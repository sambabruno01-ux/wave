Wave Voice Client
Назначение и архитектура
Wave — легковесный клиент голосовой связи для Windows, ориентированный на передачу аудиопотока с минимальной задержкой. Архитектура построена на базе прямого бинарного транспорта WebSockets и обработки несжатого 16-битного PCM-сигнала (16 кГц) без промежуточного кодирования. Графический интерфейс разработан с использованием библиотеки PyQt6 и стилизован под компоненты Windows 11 Fluent Design.

Аудиодвижок и цифровая обработка сигналов (DSP)
В приложение интегрирован комплекс алгоритмов обработки звукового тракта:

Пороговый гейт чувствительности (VAD Gate): отсекает фоновые шумы и срабатывает только при начале речи; встроенный таймер удержания (Hold Time) предотвращает обрывы тихих согласных и окончаний слов.

Многополосный эквалайзер: корректирует частотный баланс входящих аудиопотоков по готовым пресетам (Flat, Discord Crisp, Warm Broadcast, Gamer Clarity, Deep Bass).

Программные фильтры: система подавления эха (AEC), спектральный шумоподавитель (Noise Suppression) и автоматическая регулировка усиления (AGC).

Сквозное тестирование микрофона: функция «Слышать себя» запрашивает возврат аудиопакетов непосредственно через сервер, позволяя оценить итоговое качество звука и задержку точно так же, как их слышат другие участники комнаты.

Руководство пользователя

Подключение к голосовой комнате:
На стартовом экране укажите ваш псевдоним и идентификатор комнаты. Если комната уже существует, введите установленный создателем пароль для входа. Если комнаты нет, она будет автоматически зарегистрирована с заданным вами паролем.

Управление в процессе диалога:
В основном окне комнаты отображается список активных участников с текущим сетевым пингом и визуальной индикацией речи. Для каждого собеседника доступна индивидуальная регулировка громкости (через вертикальное перетаскивание курсора по иконке звука или вращение колесика мыши). Нижняя панель предоставляет быстрое переключение микрофона (Mute), входящего звука (Deafen) и режима прослушивания себя. В правой части окна расположен текстовый чат с поддержкой ссылок.

Игровой оверлей и фоновое использование:
Приложение может работать в фоновом режиме поверх любых полноэкранных игр. Доступно три режима оверлея: только карточки собеседников, карточки с вашей панелью, либо компактные плашки статуса микрофона и звука. Настройка масштаба и координат по осям X/Y позволяет точно спозиционировать оверлей на мониторе любого разрешения.

Глобальные горячие клавиши:
Взаимодействие с клиентом (отключение микрофона, глушение звука, сворачивание в трей и переключение видимости оверлея) привязано к Win32 API хоткеям. Комбинации настраиваются интерактивно в меню параметров и перехватываются глобально из любого приложения без потери фокуса ввода.

Сохранение конфигурации:
Все параметры звуковых устройств, биндов, порогов чувствительности и координат оверлея сохраняются в постоянный файл конфигурации в системной директории %AppData%\Wave\settings.json.
